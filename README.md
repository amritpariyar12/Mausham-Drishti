# 🌦️ Mausham Drishti

Mausham Drishti is a responsive weather web application that provides real-time weather information for searched cities using the OpenWeather API.

The project was built to practice working with APIs, JavaScript, responsive UI design, dynamic data rendering, and interactive maps.

## ✨ Features
- 🔎 Search weather by city
- 🌡️ Current temperature and feels-like temperature
- 📊 Minimum and maximum temperature
- 💧 Humidity and atmospheric pressure
- 💨 Wind speed and direction
- 👁️ Visibility information
- 🌅 Sunrise and sunset time
- 🌦️ Weather-based background images
- ☀️ Day and night weather themes
- 🏙️ Weather comparison for selected cities
- 🌫️ Air Quality Index (AQI)
- ☀️ UV Index
- 🗺️ Interactive map using Leaflet
- 🌙 Dark mode
- 🕐 Current date and time
- 🧠 Weather knowledge quiz
- 📱 Responsive design

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Bootstrap
- OpenWeather API
- Leaflet.js
- OpenStreetMap

## 📌 How It Works
1. The user searches for a city.
2. The application requests weather data from the OpenWeather API.
3. The weather information is displayed dynamically on the page.
4. The background changes according to the current weather condition
   and time of day.
5. The map displays the selected location.
6. Additional weather information such as AQI and UV index is displayed
   using the location coordinates.
